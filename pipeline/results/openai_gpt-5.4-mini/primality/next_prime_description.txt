## 2) Analyze the problem

### Problem definition
Given an integer `n`, return:

- `2` if `n <= 1`
- otherwise, the **smallest prime number strictly greater than `n`**

This is essentially computing the **next prime** after `n`.

### Complexity
A straightforward primality-based approach is sufficient:

- Check numbers `n+1, n+2, ...` until a prime is found.
- Each primality test can be done in `O(sqrt(k))`.
- In practice, this is efficient for small-to-moderate integers.

---

## 3) Design the algorithm

### Step-by-step approach

1. If `n <= 1`, return `2`.
2. Set `candidate = n + 1`.
3. While `candidate` is not prime:
   - increment `candidate`
4. Return `candidate`.

### Prime test
To test whether `x` is prime:

- If `x < 2`, not prime
- If `x == 2`, prime
- If `x` is even, not prime
- Otherwise, test odd divisors from `3` to `sqrt(x)`.

---

## 4) Handle edge cases

### Edge cases covered
- `n < 0` → return `2`
- `n = 0` → return `2`
- `n = 1` → return `2`
- `n = 2` → return `3`
- Prime input like `n = 3` → return next prime, `5`

### Additional considerations
- Large inputs may require a more optimized primality test if performance matters.
- For the given suite, the simple method is enough.

## Pseudocode

```python
def f(n):
    if n <= 1:
        return 2

    candidate = n + 1
    while not is_prime(candidate):
        candidate += 1

    return candidate


def is_prime(x):
    if x < 2:
        return False
    if x == 2:
        return True
    if x % 2 == 0:
        return False

    d = 3
    while d * d <= x:
        if x % d == 0:
            return False
        d += 2

    return True
```
