### 2) Analyze the Problem

We need an algorithm to determine whether an integer is prime.

A prime number is an integer greater than 1 with no positive divisors other than 1 and itself.

Important inference:
- `True` is treated as invalid/false, not as `1`, even though in Python `bool` is a subclass of `int`. So the implementation should explicitly exclude `bool`.

Complexity:
- A straightforward primality check by testing divisors up to `sqrt(n)` is appropriate.
- Time complexity: `O(sqrt(n))`
- Space complexity: `O(1)`

### 3) Design the Algorithm

#### Step-by-step approach

1. **Validate type**
   - If input is not a plain integer type, raise:
     `TypeError("is_prime() takes (1) int type parameter. Given: <class '...'>.")`
   - Also reject `bool`.

2. **Handle small integers**
   - If `n < 2`, return `False`
   - If `n == 2` or `n == 3`, return `True`

3. **Eliminate obvious composites**
   - If `n % 2 == 0`, return `False`
   - If `n % 3 == 0`, return `False`

4. **Check possible divisors efficiently**
   - Only test numbers of the form `6k ± 1`
   - Start at `i = 5`
   - While `i * i <= n`:
     - if `n % i == 0`, return `False`
     - if `n % (i + 2) == 0`, return `False`
     - increment `i` by `6`

5. **If no divisor found**
   - return `True`

#### Boolean values

- `False` should also return `False`

#### Small numbers

#### Large numbers
- The `sqrt(n)` method is efficient enough for large integers like `9223372036854775783`

### Pseudocode

```python
def is_prime(n):
    if type(n) is not int:
        raise TypeError(f"is_prime() takes (1) int type parameter. Given: {type(n)}.")

    if n < 2:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False

    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6

    return True
```
