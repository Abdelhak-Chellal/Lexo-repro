### Efficient Prime Search

For small values, trial division works well:

- Maintain a list of found primes.
- Test each candidate number starting from 2.
- A candidate is prime if it is not divisible by any previously found prime up to `sqrt(candidate)`.

Pseudo-logic:

```text
function nth_prime(n):
    if type is not int-like:
        raise TypeError
    if n < 0:
        raise ValueError

    primes = []
    candidate = 2

    while len(primes) <= n:
        is_prime = true
        for p in primes:
            if p * p > candidate:
                break
            if candidate % p == 0:
                is_prime = false
                break
        if is_prime:
            primes.append(candidate)
        candidate += 1

    return primes[n]
```
