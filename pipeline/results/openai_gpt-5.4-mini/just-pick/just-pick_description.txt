### 1) What the test suite shows

The function `f(obj, ...keys)` returns a **new object containing only selected properties** from `obj`.

It behaves like a **property picker**:

- Keeps only keys that exist in the source object
- Preserves the order of the requested keys
- Ignores duplicate requested keys
- Ignores invalid keys such as:
  - keys not in the object
  - `None`/`null` elements inside an array
  - non-string keys like `1`
- Accepts keys either as:
  - a single array/list of keys
  - multiple separate key arguments

### 2) Problem definition

Given:

- a source object `obj`
- a set of key selectors passed either as:
  - one array argument, or
  - multiple key arguments

Return a new object containing only those entries from `obj` whose keys were requested, in the same order as requested, with duplicates removed.

If `obj` is `null`, the function attempts to check membership and throws an error.
If the selector list is `null`, it throws when trying to read `.length`.

So the function does **not** safely handle null inputs; it follows the observed runtime behavior.

---

### 3) Algorithm design

#### Step-by-step behavior

1. **Parse the key arguments**
   - If the function receives exactly one selector argument and that argument is an array, use it as the key list.
   - Otherwise, treat all arguments after `obj` as the key list.

2. **Initialize an empty result object**
   - `result = {}`

3. **Iterate through the requested keys in order**
   - For each key `k`:
     - Skip it if it is `null`/`None`
     - Skip it if it is not a valid property key type (as implied by tests, numeric `1` is ignored)
     - Skip it if `k` is already added to `result` (prevents duplicates)
     - Skip it if `k` is not a property in `obj`
     - Otherwise, copy:
       - `result[k] = obj[k]`

4. **Return `result`**

---

### 4) Pseudocode

```text
function f(obj, ...selectors):
    if selectors has exactly one element and that element is an array:
        keys = selectors[0]
    else:
        keys = selectors

    result = {}

    for k in keys:
        if k is null:
            continue
        if type of k is not string:
            continue
        if k already in result:
            continue
        if k in obj:
            result[k] = obj[k]

    return result
```

---

### 5) Important edge cases

- `f({}, ['a']) -> {}`
- `f(obj, []) -> {}`
- `f(obj, ['a', 'a']) -> {'a': ...}` because duplicates are removed
- `f(obj, ['c', 'a'])` preserves order: `{'c': ..., 'a': ...}`
- `f(obj, ['a', None, 'c'])` skips `None`
- `f(obj, [1, 'a'])` skips non-string key `1`
- `f(obj, ['a', 'toString'])` includes only own/in-object properties, not inherited ones
- `f(obj, None)` throws because selector list is not valid
- `f(None, ['a'])` throws because membership check is attempted on null

---

### 6) Complexity

Let:

- `n` = number of requested keys

Then:

- **Time:** `O(n)`
- **Space:** `O(n)` in the worst case for the result object

---

### 7) Final functional description

This function is a **key-picker / object subsetting utility** that returns a new object containing the requested properties of an input object, preserving request order and removing duplicates, while ignoring missing or invalid keys.
