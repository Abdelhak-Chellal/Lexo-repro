The function is essentially **`filter` for object properties**: it returns a new object containing only the key-value pairs for which a predicate function returns a truthy value.

## 1) What the tests imply

### Inputs
- A dictionary/object `obj`
- A predicate given as a function-like string, e.g.:
  - `function(key, value) { return value < 6; }`

### Output
- A new object with only the entries that satisfy the predicate
- Preserves original key-value pairs for matching items
- Returns `{}` if nothing matches

### Error behavior
- If the object is `null` / `None`:
  - throw `Cannot convert undefined or null to object`
- If the predicate is missing / `None`:
  - throw `predicate is not a function`
- If the predicate references an undefined variable:
  - let the runtime error propagate, e.g. `obj is not defined`

## 2) Problem definition

Given an object and a predicate function, iterate over each own key-value pair and include it in the result only if the predicate returns a truthy value.

This matches the behavior of JavaScript-like object filtering:
- predicate receives `(key, value)`
- if predicate is omitted or invalid, throw
- if object is `null`/`undefined`, throw

## 3) Algorithm

### Step-by-step
1. Validate that `obj` is not `null`/`None`.
   - If it is, throw `Cannot convert undefined or null to object`
2. Validate that `predicate` is a function.
   - If not, throw `predicate is not a function`
3. Create an empty result object.
4. For each key in `obj`:
   - Read `value = obj[key]`
   - Call `predicate(key, value)`
   - If the result is truthy, copy `key: value` into the result
5. Return the result object

## 4) Truthiness rules from tests

The predicate return value is treated with normal truthiness:
- `true`, nonzero numbers, non-empty strings, objects → keep
- `false`, `0`, `''`, `None/null` → drop

Examples:
- `return value;` keeps `3`, `5` but drops `0`, `false`, `''`, `None`
- `return !!value;` keeps only truthy values
- `return value == null;` keeps only `None/null`

## 5) Edge cases

### Empty object
- Input `{}` returns `{}` regardless of predicate, as long as no error is thrown

### Predicate with one parameter
- `function(key) { return true; }` still works
- Extra arguments can be ignored by the predicate

### String/object-specific checks
The predicate may use:
- `key.length`
- `key[0]`
- `key.indexOf(...)`
- `value.length`
- numeric comparisons
- strict equality/inequality

So the algorithm must pass:
- `key` as the property name string
- `value` as the property value

## 6) Complexity

If the object has `n` properties:
- **Time:** `O(n)`
- **Space:** `O(k)` for the output object, where `k` is the number of kept entries

## 7) Pseudocode

```text
function f(obj, predicate):
    if obj is null or undefined:
        throw "Cannot convert undefined or null to object"

    if predicate is not a function:
        throw "predicate is not a function"

    result = {}

    for each key in obj:
        value = obj[key]
        if predicate(key, value) is truthy:
            result[key] = value

    return result
```

## 8) Summary

This function is a **property-filtering routine**:
- input: object + predicate
- output: new object containing only entries where predicate(key, value) is truthy
- errors match JavaScript-like runtime behavior for invalid inputs
