### What the function does

`f` takes a **list** as its first argument and then any number of additional arguments.  
It returns a **new list containing the elements from the first list that are not present in any of the later arguments**.

In other words, it performs a **filter/remove-by-membership** operation using all extra arguments as removal values.

---

## 1) Understand the test suite

From the examples:

- `f([1, 2, 3], [2]) -> [1, 3]`  
  Removes `2`.
- `f([1, 2, 3], [2, 3]) -> [1]`  
  Removes both `2` and `3`.
- `f([1, 2, 3], [2], [3]) -> [1]`  
  Multiple extra arguments are combined.
- `f([1, 2, 3], []) -> [1, 2, 3]`  
  Empty list removes nothing.
- `f([1, 2, 3], None) -> [1, 2, 3]`  
  Non-list / non-set-like removal values are ignored.
- `f([1, 2, 3], 5) -> [1, 2, 3]`  
  Scalar removal arg is ignored.
- `f([1, 2, 3]) -> [1, 2, 3]`  
  With no removal args, return original list unchanged.
- `f([1, 2, 2, 3], [2]) -> [1, 3]`  
  Removes all occurrences of matching values.
- Type-sensitive equality is used:
  - `1` and `'1'` are different
  - `True` and `1` are different in these tests
  - `None` and `False` are removable only if explicitly present
- Nested lists are treated as atomic elements:
  - `f([1, [2], 3], [[2]]) -> [1, [2], 3]`
  - because `[2]` in the list is not equal to `[[2]]`

---

## 2) Analyze the problem

### Problem definition
Given:
- a source list `arr`
- zero or more additional arguments

Return a list containing those elements of `arr` that are **not equal to any element found inside any additional argument that is a list/iterable of values**.

### Important behavior inferred
- Only **list-like additional arguments** are used for removal.
- If an additional argument is not a list (e.g. `None`, `5`), ignore it.
- Removal is based on **equality**, not identity.
- Remove **all matching occurrences** from the source list.
- Preserve original order.

---

## 3) Design the algorithm

### Step-by-step approach

1. **If there are no extra arguments**, return a copy of the input list.
2. **Collect all removable values** from each extra argument that is a list.
   - Ignore `None`, scalars, and non-list values.
3. **Scan the source list** from left to right.
4. For each item in the source list:
   - if it equals any removable value, skip it
   - otherwise, keep it
5. Return the filtered list.

---

## 4) Edge cases

### Covered/important edge cases
- Empty source list: return `[]`
- No removal arguments: return source unchanged
- `None` or scalar removal arguments: ignore them
- Duplicate removals: harmless
- Duplicate source values: remove all matching ones
- Mixed types: use equality as-is, so `1 != '1'`
- Nested lists: only remove if the exact nested structure matches

---

## Pseudocode

```python
def f(arr, *args):
    if not args:
        return list(arr)

    removals = []
    for arg in args:
        if isinstance(arg, list):
            removals.extend(arg)

    result = []
    for x in arr:
        if x not in removals:
            result.append(x)

    return result
```

---

## Complexity

Let:
- `n` = length of source list
- `m` = total number of removable elements across all valid extra list arguments

### Time
- `O(n * m)` in the straightforward implementation using `in` on a list

### Space
- `O(m)` for stored removals, plus `O(n)` for output

---

## Final interpretation

The function is essentially:

> **Remove from the first list every element that appears in any later list argument; ignore non-list extra arguments; preserve order; compare by equality.**
