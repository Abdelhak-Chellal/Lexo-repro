### 1) Understand the Test Suite

The function `f` takes a **list/array as its first argument** and then one or more additional arguments that may or may not be arrays.

From the tests, the function returns a version of the first array with certain elements removed.

Key observations:

- `f([1, 2, 3], [2]) -> [1, 3]`
- `f([1, 2, 2, 3], [2]) -> [1, 3]`
  - removes **all occurrences** of values found in the removal array
- `f([1, 2, 3], [2, 3], [1]) -> []`
  - all extra array arguments are combined as removal values
- `f([1, 2, 3], None) -> [1, 2, 3]`
- `f([1, 2, 3], 5) -> [1, 2, 3]`
- `f([1, 2, 3], 'not-an-array') -> [1, 2, 3]`
  - non-array arguments are ignored
- Comparison is **strict / identity-like**, not string-coerced:
  - `3` does not equal `'3'`
  - `1`, `True`, `False`, `None` are treated distinctly
- Nested objects/arrays are compared by **reference**, not deep equality:
  - `{'a': 1}` in one list does not match another separately created `{'a': 1}`
  - `[[1]]` in the source is not removed by passing a separate `[[1]]`

So the function behaves like a **multi-argument array difference / subtraction** using only valid array arguments after the first.

### 2) Analyze the Problem

#### Problem Definition
Given:
- a source list `A`
- zero or more additional arguments `B1, B2, ...`

Return a new list containing elements of `A` except those that appear in any of the additional arguments that are themselves arrays/lists.

#### Matching Rules
- Only consider extra arguments that are arrays/lists.
- Remove elements from `A` if they are **strictly equal** to any element in the collected removal arrays.
- Preserve order of remaining elements.
- Remove all occurrences from `A`, not just the first.
- Do not mutate the original input list.

This is essentially a `difference` operation with filtering of non-array inputs.

#### Complexity
Let:
- `n = len(A)`
- `m = total number of elements across all valid removal arrays`

A straightforward algorithm uses a hash/set for primitive values and a list-based fallback for objects if identity semantics are required. Given the tests, strict equality with reference semantics suggests a membership structure that respects identity for non-primitives.

### 3) Design the Algorithm

#### Step-by-step approach

1. Initialize an empty collection `remove_values`.
2. For each argument after the first:
   - If it is an array/list, add each of its elements to `remove_values`.
   - Otherwise ignore it.
3. Traverse the first array `A` from left to right.
4. Keep an element only if it is **not contained** in `remove_values`.
5. Return the filtered result.

#### Important detail: equality semantics
The tests imply strict matching:
- numbers match only same numbers
- booleans match only same booleans
- strings match only same strings
- arrays/objects match only if they are the same instance/reference, not structurally equal

So the containment check must behave like:
- primitive strict equality
- reference identity for objects/arrays

### 4) Handle Edge Cases

#### Covered by tests
- Empty source array: `f([], []) = []`
- No valid removal arrays: returns source unchanged
- Multiple removal arrays
- Duplicate removal values
- Duplicate source values
- Non-array extra args ignored
- `None` ignored
- Type distinctions preserved (`3` vs `'3'`, `1` vs `True`)
- Nested arrays/objects compared by reference, not deep equality

#### Additional edge cases to consider
- First argument not being an array:
  - Not shown in tests, but a robust implementation should decide whether to return empty, throw, or coerce. Based on the suite, the function seems intended to accept an array first.
- Very large inputs:
  - Use a set/identity-based membership structure for efficiency.
- Immutability:
  - Return a new array rather than modifying input.

## Concise Algorithm Description

**Function behavior:**  
Return a new array containing elements of the first array that do not appear in any later argument that is an array. Ignore all non-array later arguments. Use strict/reference equality for comparisons.

### Pseudocode

```text
function f(source, ...args):
    remove_values = empty collection

    for arg in args:
        if arg is an array:
            for item in arg:
                add item to remove_values

    result = empty array
    for item in source:
        if item not in remove_values:
            append item to result

    return result
```

### Interpretation
This is equivalent to:

- `source.filter(x => x is not contained in any valid removal array)`

with strict equality semantics.
