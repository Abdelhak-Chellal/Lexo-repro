# Algorithm Design: Right-Justified String Padding Function

## 1. Understanding the Test Suite

The function `f` takes up to three arguments:
- **arg1**: The value to be padded (string, number, boolean, or None)
- **arg2**: The total width of the resulting string
- **arg3** (optional): The padding character (defaults to space `' '`)

The function **right-justifies** the first argument within a field of the specified width, padding on the left with the specified character.

## 2. Key Observations from Test Cases

| Pattern | Observation |
|---------|-------------|
| `f('hello', 10)` → `'     hello'` | Default pad char is space `' '` |
| `f('hello', 3)` → `'hello'` | If width ≤ string length, return string as-is |
| `f('hello', 8, '0')` → `'000hello'` | Custom pad character used |
| `f('', 5)` → `'     '` | Empty string → all padding |
| `f(123, 6)` → `'   123'` | Non-string inputs are converted to string |
| `f(None, 5)` → `' null'` | None → `'null'` (lowercase) |
| `f(True, 6)` → `'  true'` | Booleans → lowercase string |
| `f('hello', 10, '')` → `'     hello'` | Empty string pad char → default to space |
| `f('hello', 10, None)` → `'     hello'` | None pad char → default to space |
| `f('hello', 10, 'ab')` → `'abababababhello'` | Multi-char pad string is repeated and truncated |
| `f('hello', 0)` → `'hello'` | Width ≤ 0 → return string as-is |
| `f('hello', 5, False)` → `'hello'` | Falsy pad char (False) → default to space, but width equals length so no padding needed |
| `f('', 0)` → `''` | Empty string with width 0 → empty string |

## 3. Algorithm

```
FUNCTION f(value, width, pad_char=None):

    // Step 1: Convert value to string
    IF value is None:
        str_value = "null"
    ELSE IF value is a boolean:
        str_value = lowercase string of value ("true" or "false")
    ELSE:
        str_value = string representation of value

    // Step 2: Determine effective pad character
    IF pad_char is None OR pad_char is empty string OR pad_char is False:
        effective_pad = ' '
    ELSE:
        effective_pad = string representation of pad_char

    // Step 3: If width <= length of str_value, return str_value as-is
    IF width <= length(str_value):
        RETURN str_value

    // Step 4: Calculate padding needed
    padding_needed = width - length(str_value)

    // Step 5: Build the padding string
    IF length(effective_pad) == 1:
        // Single character: repeat it
        padding = effective_pad repeated padding_needed times
    ELSE:
        // Multi-character pad string: repeat and truncate
        REPEAT effective_pad enough times to cover padding_needed
        TRUNCATE to exactly padding_needed characters

    // Step 6: Return padding + str_value
    RETURN padding + str_value
```

## 4. Edge Cases Handled

| Edge Case | Handling |
|-----------|----------|
| `width <= len(str_value)` | Return original string unchanged |
| `width <= 0` | Return original string unchanged |
| Empty string input | Return padding only (width characters of pad) |
| `width == 0` with empty string | Return empty string |
| `None` as value | Convert to `"null"` |
| Boolean values | Convert to lowercase `"true"`/`"false"` |
| Numeric values | Convert to string representation |
| `None` as pad_char | Default to space `' '` |
| Empty string as pad_char | Default to space `' '` |
| `False` as pad_char | Default to space `' '` |
| Multi-character pad string | Repeat and truncate to exact padding length |
| Very large width (e.g., 100) | Repeat pad string sufficiently and truncate |
