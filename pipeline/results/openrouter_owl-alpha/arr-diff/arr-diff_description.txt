# Algorithm Design for Function `f`

## 1. Understanding the Test Suite

From the I/O pairs, I can observe the following patterns:

- **Input**: A primary array as the first argument, followed by one or more additional arrays (or non-array values) as subsequent arguments.
- **Output**: A new array containing elements from the primary array that are **not present** in any of the subsequent arrays.
- **Key behaviors**:
  - Elements are removed based on **value equality** (using strict `===` / `==` semantics, as seen with `None`, `0`, `False`, `True`, `1`, `''` — note that `0` removes both `0` and `False`, and `1` is not removed by `0`, suggesting standard JS-like equality).
  - Duplicates in the primary array are all removed if the value appears in any exclusion array.
  - If a subsequent argument is not an array (e.g., `None`, `'not an array'`), it is **ignored**.
  - Empty arrays as exclusion arguments have no effect.
  - The order of the result preserves the original order of the primary array.

## 2. Problem Definition

**Problem**: Given a primary array and a variable number of exclusion arrays, return a new array containing only the elements from the primary array that do not appear in any of the exclusion arrays.

**Complexity**: O(n × m) where n is the size of the primary array and m is the total number of elements across all exclusion arrays.

## 3. Algorithm Design

```
FUNCTION f(primaryArray, ...exclusionArrays):
    
    // Step 1: Validate primaryArray
    IF primaryArray is not an array:
        RETURN primaryArray (or handle as edge case)
    
    // Step 2: Build a Set of values to exclude
    exclusionSet = new Set()
    
    FOR EACH exclusionArg IN exclusionArrays:
        IF exclusionArg is an array:
            FOR EACH element IN exclusionArg:
                ADD element TO exclusionSet
    
    // Step 3: Filter primaryArray
    result = []
    
    FOR EACH element IN primaryArray:
        IF element is NOT IN exclusionSet:
            APPEND element TO result
    
    // Step 4: Return result
    RETURN result
```

## 4. Edge Cases Handled

| Edge Case | Behavior |
|---|---|
| Empty primary array | Returns `[]` |
| Empty exclusion arrays | Returns primary array unchanged |
| Non-array exclusion arguments | Ignored |
| Duplicate values in primary | All instances removed if value is excluded |
| Falsy values (`None`, `0`, `False`, `''`) | Handled via Set membership |
| All elements excluded | Returns `[]` |
| No elements excluded | Returns primary array unchanged |
| Multiple exclusion arrays | Union of all exclusion values used |

## Implementation (JavaScript)

```javascript
function f(primaryArray, ...exclusionArrays) {
    // Build exclusion set from all valid array arguments
    const exclusionSet = new Set();
    
    for (const arg of exclusionArrays) {
        if (Array.isArray(arg)) {
            for (const element of arg) {
                exclusionSet.add(element);
            }
        }
    }
    
    // Filter primary array
    return primaryArray.filter(element => !exclusionSet.has(element));
}
```
