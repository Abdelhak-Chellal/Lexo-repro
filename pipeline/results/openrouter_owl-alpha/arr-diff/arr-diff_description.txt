# Algorithm Design: Array Difference Function

## Problem Analysis

Based on the test suite, the function `f` performs a **multi-set difference** operation:

- **Input**: A primary array followed by one or more exclusion arrays (or values)
- **Output**: Elements from the primary array that are NOT present in ANY of the exclusion arrays
- **Key behaviors**:
  - Returns empty array if primary is empty
  - Returns full primary array if no valid exclusion arrays provided
  - Handles multiple exclusion arrays (union of all exclusions)
  - Ignores non-array arguments (treats them as no exclusions)
  - Preserves duplicates in the result
  - Uses strict equality for comparison

## Algorithm

```python
def f(primary_array, *exclusion_args):
    """
    Returns elements from primary_array that are not present in any exclusion arrays.
    
    Args:
        primary_array: The source array to filter
        *exclusion_args: Variable number of exclusion arrays
    
    Returns:
        Filtered array with elements not found in any exclusion array
    """
    
    # Step 1: Handle empty primary array
    if not primary_array:
        return []
    
    # Step 2: Collect all exclusion values from valid exclusion arrays
    exclusion_set = set()
    has_valid_exclusion = False
    
    for arg in exclusion_args:
        # Only process array-like arguments (lists/tuples)
        if isinstance(arg, (list, tuple)):
            has_valid_exclusion = True
            exclusion_set.update(arg)
    
    # Step 3: If no valid exclusion arrays, return primary array as-is
    if not has_valid_exclusion:
        return list(primary_array)
    
    # Step 4: Filter primary array - keep elements NOT in exclusion set
    result = []
    for element in primary_array:
        if element not in exclusion_set:
            result.append(element)
    
    return result
```

## Step-by-Step Explanation

### Step 1: Handle Empty Primary Array
- If `primary_array` is empty, immediately return `[]`
- This covers test cases: `f([], [1, 2])`, `f([], [])`

### Step 2: Process Exclusion Arguments
- Iterate through all arguments after the primary array
- Only consider arguments that are arrays (lists/tuples)
- Ignore non-array types: strings, numbers, None, booleans, dicts
- Collect all values from valid exclusion arrays into a set for O(1) lookup

### Step 3: No Valid Exclusions
- If no valid exclusion arrays found, return the primary array unchanged
- This handles: `f([1,2,3])`, `f([1,2,3], 'not an array')`, etc.

### Step 4: Filter Primary Array
- Iterate through each element in primary array
- Check if element is NOT in the exclusion set
- If not excluded, add to result
- Preserves order and duplicates from original array

## Edge Cases Handled

| Edge Case | Example | Result |
|-----------|---------|--------|
| Empty primary | `f([], [1,2])` | `[]` |
| No exclusions | `f([1,2,3])` | `[1,2,3]` |
| All excluded | `f([1,2,3], [1,2,3])` | `[]` |
| No matches | `f([1,2,3], [4,5,6])` | `[1,2,3]` |
| Multiple exclusions | `f([1,2,3], [1], [2])` | `[3]` |
| Non-array args | `f([1,2,3], 42)` | `[1,2,3]` |
| Mixed types | `f([1,'1',True], [1])` | `['1',True]` |
| Duplicates | `f([1,1,2,2,3], [1,2])` | `[3]` |

## Complexity

- **Time**: O(n + m) where n = primary array length, m = total exclusion elements
- **Space**: O(m) for the exclusion set + O(n) for result array
