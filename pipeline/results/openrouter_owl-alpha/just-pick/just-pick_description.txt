## Algorithm Analysis

### Understanding the Test Suite

The function `f` takes a dictionary and one or more keys (either as a list or as individual arguments) and returns a new dictionary containing only the key-value pairs where the key exists in the original dictionary.

**Key observations from the test cases:**

1. **Flexible input format**: Keys can be passed as a single list `['a', 'c']` or as individual arguments `'a', 'c'`.
2. **Filtering behavior**: Only keys that exist in the source dictionary are included in the result.
3. **Missing keys are silently ignored**: If a key doesn't exist in the source dict, it's simply skipped (no error).
4. **Duplicate keys are handled**: `['a', 'a']` produces `{'a': 3}` — no duplicates in output.
5. **Order preservation**: The output dictionary preserves the order of the requested keys (e.g., `['b', 'a']` → `{'b': 2, 'a': 1}`).
6. **Falsy values are preserved**: `None`, `False`, `0`, `''` are all valid values.
7. **Edge cases**: Empty dict, empty key list, nested values, special keys (empty string, spaces, `__proto__`, `constructor`) all work.
8. **Null input throws**: Passing `None` as the dictionary throws a `TypeError`.

### Problem Definition

**Input:**
- `source`: A dictionary (or object) with key-value pairs.
- `keys`: Either a single array of keys, or one or more individual key arguments (variadic).

**Output:**
- A new dictionary containing only the key-value pairs from `source` where the key is present in both `source` and the requested `keys`.

### Algorithm Design

```
FUNCTION f(source, ...args):
    1. If source is None/null:
         THROW TypeError ("Cannot use 'in' operator to search for ... in null")
    
    2. Normalize the keys into a single list:
         IF args has exactly 1 element AND that element is an array/list:
             key_list ← args[0]
         ELSE:
             key_list ← args  (treat all args as individual keys)
    
    3. Initialize an empty result dictionary: result ← {}
    
    4. FOR each key in key_list:
         IF key exists in source (using 'in' operator):
             result[key] ← source[key]
         ELSE:
             SKIP (do nothing)
    
    5. RETURN result
```

### Step-by-Step Walkthrough

| Step | Action | Example |
|------|--------|---------|
| 1 | Validate source is not null | `f(None, ['a'])` → throws TypeError |
| 2 | Normalize keys to a flat list | `f(d, 'a', 'c')` → keys = `['a', 'c']`; `f(d, ['a', 'c'])` → keys = `['a', 'c']` |
| 3 | Create empty result | `result = {}` |
| 4 | Iterate keys, check membership, copy if present | `'a' in source` → `result['a'] = source['a']` |
| 5 | Return result | `{'a': 3, 'c': 9}` |

### Edge Cases Handled

| Edge Case | Behavior |
|-----------|----------|
| Empty source dict | Returns `{}` |
| Empty key list | Returns `{}` |
| Key not in source | Silently skipped |
| Duplicate keys in request | Only one entry in result (dict keys are unique) |
| `None` as source | Throws `TypeError` |
| Falsy values (`0`, `False`, `''`, `None`) | Preserved in output |
| Special keys (`__proto__`, `constructor`, `''`, spaces) | Handled correctly |
| Nested/complex values | Copied by reference (shallow) |

### Complexity

- **Time**: O(k) where k is the number of requested keys (assuming O(1) hash lookup).
- **Space**: O(m) where m is the number of keys found in both source and request.
