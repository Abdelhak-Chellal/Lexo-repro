> ❗ **Critical Insight**:  
> The function **only considers a dot as an extension separator if it is not at the beginning of the filename component** (i.e., not a hidden file dot).  
> However, looking closely:
> - `/path/to/.hidden` → output is `/path/to/.hidden.md` → so `.hidden` is **not** stripped.
> - But `/path/to/file.txt` → becomes `/path/to/file.md` → so `.txt` **is** stripped.

> Therefore, the rule is:
> - **Only strip the extension if the dot is not the first character of the filename part** (i.e., not a leading dot in the basename).

Let’s define:
- Let `filename_part` = the part after the last `/` (or the whole string if no `/`).
- If `filename_part` starts with `.`, then **do not treat any dot as an extension** → keep entire path as base.
- Otherwise, split at the **last dot** in the full path to get base and extension.

But wait: `/path/to/file.name.txt` → becomes `/path/to/file.name.md` → so only the **last** extension is replaced.

So refined logic:

> **Extension detection rule**:
> - Find the **last dot** in the entire path.
> - If that dot is **not the first character of the filename component** (i.e., not a hidden file), then it marks the extension.
> - Otherwise, there is **no extension** to replace.

Implementation:
```python
# Get the filename (last component after '/')
filename = path.rsplit('/', 1)[-1] if '/' in path else path

# Find last dot in full path
last_dot_index = path.rfind('.')

# Determine if this dot is a valid extension separator
if last_dot_index == -1:
    # No dot at all → no extension
    base = path
elif filename.startswith('.'):
    # Hidden file → no extension to replace
    base = path
else:
    # Valid extension → split at last dot
    base = path[:last_dot_index]
```

### **Final Algorithm Steps**

```python
def f(path, new_ext='undefined', *args):
    # Step 1: Handle non-string or None
    if path is None:
        return None
    if not isinstance(path, str):
        return path
    
    # Step 2: Handle empty string
    if path == '':
        return ''
    
    # Step 3: Determine base (path without extension)
    # Extract filename component
    if '/' in path:
        filename = path.rsplit('/', 1)[1]
    else:
        filename = path
    
    last_dot = path.rfind('.')
    
    # Check if the last dot is a valid extension separator
    if last_dot == -1 or filename.startswith('.'):
        # No extension to replace
        base = path
    else:
        base = path[:last_dot]
    
    # Step 4: Append new extension
    return base + new_ext
```
