# Algorithm: Replace File Extension Function

## Problem Analysis

The function `f(filename, new_ext)` replaces the file extension of a given filename/path with a new extension. It must handle a wide variety of edge cases including paths, hidden files, multiple dots, trailing dots, special entries (`.`, `..`, `./`, `../`), and non-string inputs.

## Input/Output Specification

- **Inputs**: `filename` (can be `str`, `None`, `int`, `bool`, `list`, `dict`), `new_ext` (a `str` representing the new extension, e.g., `'.js'` or `''`)
- **Output**: The filename with its extension replaced by `new_ext`, or the original value for non-string inputs.

## Algorithm Design

### Step-by-Step Procedure

```
FUNCTION f(filename, new_ext):

    1. IF filename is None:
           RETURN None

    2. IF filename is NOT a string (e.g., int, bool, list, dict):
           RETURN filename (unchanged)

    3. IF filename is an empty string (""):
           RETURN ""

    4. SPLIT the filename into:
           - directory_part: everything up to and including the last '/' or '\\'
           - basename: everything after the last '/' or '\\'
         (If no separator found, directory_part = "", basename = filename)

    5. DETERMINE the "last meaningful dot" in the basename:
           - A "meaningful dot" is a dot that is NOT the first character of the basename.
           - Find the LAST occurrence of '.' in the basename that is:
               a) NOT at position 0 (to skip hidden file leading dot)
               b) NOT at the last position (i.e., basename does NOT end with '.')
               c) If basename ends with '.', strip all trailing dots first, then re-evaluate.

           Specifically:
           a) Strip any trailing dots from the basename → stripped_basename
           b) Find the last '.' in stripped_basename
           c) If that '.' exists AND is not at position 0:
                  name_part = stripped_basename[0 : last_dot_position]
                  (discard everything from last_dot onward)
              Else:
                  name_part = stripped_basename

    6. IF new_ext is empty (""):
           RETURN directory_part + name_part
       ELSE:
           RETURN directory_part + name_part + new_ext
```

### Detailed Sub-Algorithm for Step 5 (Finding the Extension Boundary)

```
FUNCTION find_name_part(basename):
    // Handle trailing dots: strip them
    stripped = basename.rstrip('.')

    // Find last dot in stripped version
    last_dot = stripped.rfind('.')

    // If dot exists and is not the first character (hidden file)
    IF last_dot > 0:
        RETURN stripped[0 : last_dot]
    ELSE:
        RETURN stripped
```

## Edge Cases Handled

1. **Non-string inputs**: `None`, `int`, `bool`, `list`, `dict` → returned as-is
2. **Empty string**: returns `""`
3. **Empty new extension**: strips the old extension, returns name only
4. **Hidden files** (leading dot): dot at position 0 is NOT treated as extension separator
5. **Trailing dots**: stripped before finding the extension boundary
6. **Multiple dots**: only the last meaningful dot is used
7. **Path separators**: both `/` and `\\` are handled; directory portion is preserved
8. **Special entries** (`.`, `..`, `./`, `../`): trailing dots stripped, then new extension appended
9. **Case sensitivity**: extension replacement is case-insensitive in behavior (simply replaces from last dot)

## Complexity

- **Time**: O(n) where n is the length of the filename string (single pass for `rfind` and `rstrip`)
- **Space**: O(n) for the output string
