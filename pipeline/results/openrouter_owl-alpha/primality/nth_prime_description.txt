```
INPUT:  n — a non-negative integer (bool is accepted as int subclass)
OUTPUT: the nth prime number (0-indexed)

1. VALIDATE input:
   a. If n is None or not an int (excluding bool), 
      raise TypeError: "nth_prime() takes (1) int type parameter."
   b. If n < 0, 
      raise ValueError: "int parameter must be positive or zero."

2. SPECIAL CASES:
   a. If n == 0, return 2.

3. FIND THE nth PRIME (Sieve of Eratosthenes with dynamic upper bound):
   a. Estimate an upper bound for the nth prime using the prime number theorem:
      - upper_bound ≈ n * (ln(n) + n * ln(ln(n)) for n ≥ 6
      - For small n, use a fixed small bound (e.g., 15)
   b. Create a boolean sieve array of size upper_bound + 1, initialized to True.
   c. Set sieve[0] = sieve[1] = False.
   d. For i from 2 to √upper_bound:
      - If sieve[i] is True, mark all multiples of i (from i² to upper_bound) as False.
   e. Collect all indices where sieve[i] is True into a list of primes.
   f. If the list has fewer than n+1 primes, increase the upper bound and repeat.
   g. Return primes[n].

4. RETURN the nth prime.
```
