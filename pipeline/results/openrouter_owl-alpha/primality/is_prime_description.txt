**Algorithm: `is_prime(n)`**

1.  **Handle base cases:**
    *   If `n` is less than or equal to 1, return `False` (1 and non-positive numbers are not prime).
    *   If `n` is 2 or 3, return `True` (2 and 3 are prime).
    *   If `n` is divisible by 2 or 3 (i.e., `n % 2 == 0` or `n % 3 == 0`), return `False` (even numbers greater than 2 and multiples of 3 greater than 3 are not prime).

2.  **Iterate through potential divisors:**
    *   Start checking for divisors from `i = 5`.
    *   Continue checking as long as `i * i <= n`. This is an optimization because if `n` has a factor greater than its square root, it must also have a factor smaller than its square root.
    *   In each iteration, check if `n` is divisible by `i` or `n` is divisible by `i + 2`. This step efficiently checks for factors of the form `6k-1` and `6k+1` (e.g., 5 and 7, 11 and 13, etc.), skipping multiples of 2 and 3.
    *   If `n` is divisible by `i` or `i + 2`, return `False`.
    *   Increment `i` by 6 for the next pair of potential divisors.

3.  **If no divisors found:**
    *   If the loop completes without finding any divisors, it means `n` is a prime number, so return `True`.

**Pseudocode:**

```python
def is_prime(n):
    if n <= 1:
        return False
    if n <= 3: # Handles n=2 and n=3
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False

    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6

    return True
```
