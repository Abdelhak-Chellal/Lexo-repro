### **3) Design the Algorithm**

We design a function `f(n)` that checks if `n` is prime.

#### **Algorithm Steps**:

1. **Handle edge cases**:
   - If `n <= 1`, return `False` (since primes are > 1).
2. **Check for small primes**:
   - If `n == 2` or `n == 3`, return `True`.
3. **Eliminate even numbers and multiples of 3**:
   - If `n % 2 == 0` or `n % 3 == 0`, return `False`.
4. **Check divisibility up to √n**:
   - Use a loop from `i = 5` to `√n`, incrementing by 6 (to check `i` and `i+2`, since all primes > 3 are of form 6k±1).
   - For each `i`, check if `n % i == 0` or `n % (i+2) == 0`. If yes, return `False`.
5. If no divisors found, return `True`.

This is an optimized trial division method.

---

### **4) Handle Edge Cases**

- **Negative numbers**: Not prime → return `False`.
- **0 and 1**: Not prime → return `False`.
- **2**: Smallest prime → return `True`.
- **Even numbers > 2**: Not prime → return `False`.
- **Large primes**: Handled by loop up to √n.

### **Final Algorithm (Pseudocode)**

```python
def f(n):
    if n <= 1:
        return False
    if n <= 3:
        return True
    if n % 2 == 0 or n % 3 == 0:
        return False
    i = 5
    while i * i <= n:
        if n % i == 0 or n % (i + 2) == 0:
            return False
        i += 6
    return True
```
