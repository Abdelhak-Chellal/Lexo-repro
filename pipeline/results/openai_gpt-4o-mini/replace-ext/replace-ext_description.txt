Here’s a step-by-step algorithm to achieve the required functionality:

   - If a new extension is provided, append it to the base file name (without a leading dot).

4. **Reconstruct the File Path**:
   - Combine the directory with the new file name (base name + new extension).
   - Ensure the output path retains the original structure.

5. **Return Result**:
   - Return the newly constructed file path.

### 4) Handle Edge Cases
- If the input file path is an empty string, return an empty string.
- If the input path has no extension and a new extension is given, append the new extension.
- Ensure that the function can handle both relative and absolute paths.
- Handle cases where the path has redundant components (like `./` or `../`).

Here’s a pseudocode implementation based on the above design:

```python
def f(file_path, new_extension):
    # Step 1: Input Validation
    if file_path is None:
        return None
    if not isinstance(file_path, str):
        return file_path
    if new_extension is None:
        new_extension = "null"
    
    # Step 2: Extracting Base Name and Extension
    import os
    directory, file_name = os.path.split(file_path)
    base_name, current_extension = os.path.splitext(file_name)
    
    # Step 3: Handle new extension
    if new_extension == "":
        new_file_name = base_name  # Remove current extension
    else:
        new_file_name = base_name + new_extension  # Add new extension
    
    # Step 4: Reconstruct the File Path
    new_file_path = os.path.join(directory, new_file_name)
    
    # Step 5: Return Result
    return new_file_path
```
