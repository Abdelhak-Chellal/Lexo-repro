#### Step-by-Step Approach:

2. **Determine the Upper Limit**: Calculate an upper limit to find at least `n + 1` primes. A common approximation is using `upper_limit = n * log(n) + n * log(log(n))` for large `n`.
3. **Implement the Sieve of Eratosthenes**:
   - Create a boolean list `is_prime` of size `upper_limit + 1`, initialized to `True`.

   - For each integer `i` from 2 to the square root of `upper_limit`, if `is_prime[i]` is `True`, mark all multiples of `i` as `False`.
4. **Collect the Primes**: Iterate through the `is_prime` list and collect the indices marked `True` into a list `primes`.
5. **Return the Result**: Return `primes[n]`, which corresponds to the `(n + 1)`-th prime.

def sieve_of_eratosthenes(limit):
    is_prime = [True] * (limit + 1)
    is_prime[0], is_prime[1] = False, False
    for i in range(2, int(limit**0.5) + 1):
        if is_prime[i]:
            for multiple in range(i * i, limit + 1, i):
                is_prime[multiple] = False
    return [i for i in range(limit + 1) if is_prime[i]]
