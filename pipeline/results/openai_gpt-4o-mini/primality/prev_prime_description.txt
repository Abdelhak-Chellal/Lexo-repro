### 3. Design the Algorithm
Here’s a step-by-step approach to implement the function `f(n)`:

1. **Input Validation**:
   - If `n` is not an integer, raise a `TypeError` indicating that the input must be an integer.
   - If `n` <= 2, raise a `ValueError` indicating that the parameter must be larger than 2.

2. **Find the Largest Prime Less Than n**:
   - Start from `n-1` and decrement until you find a prime number.
   - To check if a number `x` is prime:
     - If `x <= 1`, return False.
     - Check divisibility from 2 up to the square root of `x`. If `x` is divisible by any of these, it is not prime.

3. **Return the Found Prime**:
   - Once a prime is found, return it.

### Algorithm Implementation
Here’s how the algorithm can be implemented in Python:

```python
def is_prime(num):
    if num <= 1:
        return False
    for i in range(2, int(num**0.5) + 1):
        if num % i == 0:
            return False
    return True

def f(n):
    if not isinstance(n, int):
        raise TypeError(f"expect parameter n to be int. Given: {type(n)}.")
    if n <= 2:
        raise ValueError(f"expect parameter n to be larger than 2. Given: {n}.")
    
    # Start checking for prime from n-1 downwards
    for candidate in range(n - 1, 1, -1):
        if is_prime(candidate):
            return candidate
```
