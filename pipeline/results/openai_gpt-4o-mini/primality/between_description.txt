```plaintext
function f(start, end):
    if start >= end:
        return []

    result = []
    
    for num in range(start, end):
        if is_prime(num):
            result.append(num)
    
    return result

function is_prime(n):
    if n <= 1:
        return False
    for i from 2 to sqrt(n):
        if n % i == 0:
            return False
    return True
```
