4. **Start a loop** from `n`:
   - If `is_prime(i)` returns `True`, return `i`.
   - Increment `i` by 1 and continue the loop until a prime is found.

### Pseudocode

```plaintext
function f(n):
    if n <= 0:
        return 2
        
    i = n
    while true:
        if is_prime(i):
            return i
        i += 1

function is_prime(num):
    if num < 2:
        return False
    for j from 2 to sqrt(num):
        if num % j == 0:
            return False
    return True
```
