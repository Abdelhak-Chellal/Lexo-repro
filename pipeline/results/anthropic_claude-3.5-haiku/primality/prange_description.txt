The function f(n) generates the first n prime numbers in ascending order.

Key Characteristics:
1. The first prime number is always 2
2. Subsequent primes are generated sequentially
3. A prime number is a natural number > 1 that is only divisible by 1 and itself

Detailed Algorithm:

```python
def generate_primes(n):
    if n <= 0:
        return []
    
    primes = [2]  # Start with 2 as the first prime
    
    # Current number to check for primality
    candidate = 3
    
    while len(primes) < n:
        # Check if candidate is prime
        is_prime = True
        
        # Check divisibility only up to square root of candidate
        for prime in primes:
            if prime * prime > candidate:
                break
            
            if candidate % prime == 0:
                is_prime = False
                break
        
        # If prime, add to list
        if is_prime:
            primes.append(candidate)
        
        # Move to next odd number
        candidate += 2
    
    return primes
```

Time Complexity: O(n * sqrt(p)), where p is the nth prime number
Space Complexity: O(n)

Key Optimization Techniques:
1. Only check odd numbers after 2
2. Only check divisibility up to square root of candidate
3. Stop checking divisors once they exceed sqrt(candidate)

- Starting with 2

- Using a probabilistic primality test
