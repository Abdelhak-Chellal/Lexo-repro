Detailed Algorithm:

```python
def is_prime(n):
    # Prime number check function
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

def prime_range(start, end):
    # Ensure start is at least 2
    start = max(2, start)
    
    # Handle invalid range case
    if start > end:
        return []
    
    # Generate prime numbers in the range
    primes = [
        num for num in range(start, end + 1) 
        if is_prime(num)
    ]
    
    return primes
```

Algorithm Breakdown:

1. Prime Number Validation (is_prime function):
   - Check if number is less than 2 (not prime)
   - Check divisibility up to square root of number
   - Time complexity: O(√n)

2. Prime Range Extraction (prime_range function):
   - Adjust start to minimum 2
   - Handle invalid range by returning empty list
   - Use list comprehension to generate primes
   - Time complexity: O(n * √n)
