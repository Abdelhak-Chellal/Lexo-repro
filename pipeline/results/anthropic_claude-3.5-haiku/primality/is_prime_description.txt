Algorithm Design: Prime Number Checker

```python
def is_prime(n):
    # Handle edge cases
    if n <= 1:
        return False
    
    # Check for divisibility up to square root of n
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    
    return True
```

Algorithmic Breakdown:
1) If number <= 1, return False
2) Check divisibility from 2 to sqrt(n)
3) If any number divides n evenly, return False
4) If no divisors found, return True

Time Complexity: O(√n)
Space Complexity: O(1)

- Matches all test cases
