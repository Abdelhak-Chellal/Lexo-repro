Prime Number Detection Algorithm:
```python
def is_prime(n):
    # Reject non-positive numbers
    if n <= 1:
        return False
    
    # Check for divisibility up to square root
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    
    return True
```
