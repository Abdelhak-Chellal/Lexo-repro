Based on the test suite, here's an analysis and algorithm design for the function:

Algorithm: isEven

Problem Definition:
- Function checks if a given number is even
- Accepts only integer inputs
- Returns True for even numbers (including zero and negative even numbers)
- Returns False for odd numbers
- Throws error for non-numeric or non-integer inputs

Algorithm Design:

```python
def isEven(n):
    # Type and input validation
    if not isinstance(n, (int, str)):
        raise TypeError("is-odd expects a number")
    
    # Convert string inputs to integers
    if isinstance(n, str):
        try:
            n = int(n)
        except ValueError:
            raise TypeError("is-odd expects a number")
    
    # Check for floating point numbers
    if not isinstance(n, int):
        raise TypeError("is-odd expects an integer")
    
    # Even number check
    return n % 2 == 0
```

Key Algorithm Components:
1. Input Type Validation
   - Reject non-numeric types
   - Allow integer and string inputs
   - Convert valid string inputs to integers

2. Number Type Validation
   - Reject floating point numbers
   - Only accept integers

3. Even Number Check
   - Use modulo operator to determine evenness
   - Return True if number is divisible by 2 with no remainder
   - Return False otherwise

Time Complexity: O(1)
Space Complexity: O(1)

The algorithm covers all test cases:
- Even numbers (positive/negative/zero): Return True
- Odd numbers (positive/negative): Return False
- String representations of numbers: Convert and validate
- Invalid inputs: Raise appropriate type errors

This implementation provides a robust, type-safe solution for checking even numbers.
