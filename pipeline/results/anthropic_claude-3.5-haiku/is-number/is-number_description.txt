```python
def is_numeric_representation(value):
    # Handle None and boolean values
    if value is None or isinstance(value, bool):
        return False
    
    # Convert input to string if it's not already a string
    if not isinstance(value, str):
        value = str(value)
    
    # Remove leading and trailing whitespace
    value = value.strip()
    
    # Check for empty string
    if not value:
        return False
    
    # Check for different numeric representations
    try:
        # Handle decimal, hexadecimal, octal, binary, scientific notation
        float(value)
        return True
    except ValueError:
        return False
```

Algorithm Explanation:
1. First, reject None and boolean values
2. Convert non-string inputs to strings
3. Strip whitespace from the input
4. Reject empty strings
5. Use Python's float() conversion to handle:
   - Decimal numbers (positive/negative)
   - Floating point numbers
   - Scientific notation
   - Hexadecimal (0x prefix)
   - Octal (0o prefix)
   - Binary (0b prefix)

Key Features:
- Handles numeric strings
- Supports different number bases
- Handles floating point and scientific notation
- Strips whitespace
- Rejects non-numeric strings

Time Complexity: O(1)
