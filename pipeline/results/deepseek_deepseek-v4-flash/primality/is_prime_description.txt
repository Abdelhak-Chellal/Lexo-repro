The function `f(n)` returns `True` if `n` is a prime number, and `False` otherwise.  
This is determined by the test cases: `True` for 2, 3, 5, 7, 101 (all primes), and `False` for non‑primes (0, 1, 4, 6, 8, 9, 10) and all negative numbers.

### Algorithm

1. **Input**: integer `n`.  
2. **If** `n ≤ 1`, return `False`.  
3. **If** `n == 2`, return `True`.  
4. **If** `n` is even (`n % 2 == 0`), return `False`.  
5. **For** `i` from 3 up to `√n` (inclusive), stepping by 2:  
   - **If** `n % i == 0`, return `False`.  
6. **Return** `True`.

### Complexity

- **Time**: O(√n) in the worst case (when `n` is prime).  
- **Space**: O(1).  

This algorithm covers all test cases and handles edge cases (negatives, 0, 1, even numbers, and small primes).
