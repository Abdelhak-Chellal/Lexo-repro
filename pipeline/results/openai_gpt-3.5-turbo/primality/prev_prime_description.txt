Algorithm:

1) Start with the input number n.
2) Initialize a variable result to 0.
3) Check if n is greater than or equal to 4.
4) If n is greater than or equal to 4, subtract 1 from n and assign it to result.
5) Repeat steps 3 and 4 until n is less than 4.
6) Return the final result.

- The function takes an input number n and subtracts 1 from it until the number is less than 4.
- The function returns the final result after the subtraction operation is completed.
- The algorithm is designed to handle the given test cases where the output is n-1 for each input n.
