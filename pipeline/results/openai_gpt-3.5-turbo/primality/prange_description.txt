1) Create a list of numbers from 2 to n.
2) Initialize a boolean list of size n+1 to mark numbers as prime or not prime.
3) Start with the first number 2, mark it as prime, and iterate over its multiples up to n, marking them as not prime.
4) Move to the next unmarked number in the list and repeat the process until all numbers less than or equal to n are processed.
5) Finally, return a list of all numbers marked as prime.
