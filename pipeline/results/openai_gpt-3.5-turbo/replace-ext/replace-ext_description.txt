Algorithm:

1. Define a function f that takes two parameters: file_path and extension.
2. Check if file_path is None. If so, return None.
3. Check if extension is None. If so, set extension to the string "null".
4. Split the file_path by "/" to separate the directories and the file name.
5. Get the last element of the split file_path to extract the file name.
6. Concatenate the file name and the extension with a "." in between.
7. Join the directories back together with "/" and append the concatenated file name and extension.
8. Return the final file path.

This algorithm takes the file path and extension provided as input and appends the extension to the file name. If the input file path is None, the algorithm returns None. If the input extension is None, it sets the extension to the string "null" before appending it to the file name. This algorithm handles both edge cases and the test cases provided in the test suite.
