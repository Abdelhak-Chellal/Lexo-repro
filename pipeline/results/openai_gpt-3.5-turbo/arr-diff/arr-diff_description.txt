Algorithm:

1) Define the function f taking two input lists as arguments.
2) Initialize an empty list result[] to store the final output.
3) Iterate over the elements of the first input list.
4) For each element, check if it is present in the second input list.
5) If the element is present, add it to the result[] list.
6) Return the result[] list as the output.

Edge Cases:
- If both input lists are empty, return an empty list as output.
- If one of the input lists is empty, return the non-empty list as output.
- Handle cases where elements are of different types (e.g., None, True, False).
